Paired console research · Beta 4

NEXT System Control v0.5.0 Beta 4 — Paired Research Tools

Beta 4 adds a fixed read-only Tool Registry command and bounded metadata for NEXT Research Station console snapshots. Snapshot capture requires the active paired session to match the selected console and pinned host fingerprint.

Tool Registry

Read-only catalog command

The fixed tools command lists bounded registry metadata, including tool IDs, categories, mode requirements, implementation status, and declared capabilities. It does not activate or authorize tools.

NEXT Research Station integration

Console snapshot metadata

NEXT Research Station can collect the fixed Tool Registry listing as part of an explicitly requested console snapshot. Snapshot records store command status and output hashes rather than raw console output.

Paired identity

Fail-closed capture

Capture requires the active paired session to match the selected endpoint and pinned host fingerprint. NEXT Research Station checks the identity before collection and before saving.

Safeguards

Capabilities remain gated

Registry metadata is descriptive only. It does not grant authorization, elevate privileges, start services, or make arbitrary shell execution available through NEXT Shell.

PS4 testing: the maintainer confirms this exact Beta 4 package was installed and tested on PS4.

Host and build checks: OpenOrbis ELF, FSELF, and package generation completed; the PC simulator suite passed 15/15 tests and NEXT Shell sanitizer tests passed.

Installation: Install the PKG with the PS4 package installer and launch NEXT System Control. The title ID is NEXT00053, matching Beta 3.

Enable SSH or FTP only when needed on a trusted local network. FTP is not TLS-encrypted; do not expose either service to the public internet.
