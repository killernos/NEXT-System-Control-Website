NEXT System Control v0.5.0 Beta 3 — Six Themes & Debugger Diagnostic

The main release feature is the themed dashboard with six selectable palettes, Explorer and Developer startup modes, and a controller-driven Tool Library. This package also tests the manual debugger query against the console's detected local IPv4; on-console testing returned errno 61 on TCP 744.

Main feature · Personalization

Modern dashboard & six themes

Rounded panels, clear focus indicators, and compact status cards. Choose Matrix Green, Cyber Blue, Royal Purple, Crimson Red, Amber Gold, or Monochrome. The dashboard and startup selector follow your saved theme.

Navigation

Explorer & Developer modes

Choose your mode at startup. Explorer offers read-only system information, filesystem navigation, monitoring, and diagnostics. Developer tools remain capability-gated; choosing Developer mode does not automatically elevate privileges or start services.

Quick access

Tool Library & saved preferences

Browse categories, favorites, and recent tools; search with the native PS4 keyboard. Theme, favorites, recents, and category preferences are saved between launches.

Improvements

PS4 keyboard, SSH & alignment

Restored native PS4 password entry, improved credential handling and SSH reconnect behavior, and corrected dashboard banner layering and navigation icon alignment.

Dashboard and theme testing: the maintainer reports the Beta 3 package was tested on PS4. The diagnostic result below concerns the separate read-only debugger query.

Quick controls: Square from System Info opens themes; choose with the D-pad and apply with Cross. L2 opens the Tool Library; Left/Right changes category; Triangle searches; R2 clears search; Circle returns.

Debugger diagnostic result: NEXT displayed the detected console-local address and attempted TCP 744, which returned errno 61 (connection refused). This does not establish that ps4debug-NG started or that a debugger server is listening; successful debugger connectivity is not claimed.

Debugger diagnostic

Detected local IPv4 target

The manual read-only query uses the console's freshly detected local IPv4 on port 744 rather than assuming loopback routing. It accepts no user-supplied remote address.

Manual only

Explicit query

No connection is attempted automatically. Open the GoldHEN / PS4Debug diagnostic screen and press X to run the query.

Safeguards

Read-only client

NEXT does not load or resend a payload, attach to processes, access process memory, modify the kernel, or grant privileges.

Build checks: OpenOrbis compilation, FSELF, package generation, ASan/UBSan debugger-client tests, the real Linux loopback protocol test, and UI regression tests passed. Host tests do not substitute for the PS4 diagnostic result.

Installation: Download the PKG, install it with the PS4 package installer, and launch NEXT System Control. Package title ID: NEXT00053 (a separate application entry).

Enable SSH or FTP only when needed on a trusted local network. FTP is not TLS-encrypted; do not expose either service to the public internet.
