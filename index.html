Public beta now available

NEXT System Control v0.5.0 Beta 1

Revision 21 has been tested on a PS4 running firmware 12.00 with GoldHEN. Includes SSH diagnostics (port 2222), FTP access (port 2122), and read-only on-console filesystem navigation. This is a beta release; other firmware versions are not yet verified.

Security: FTP does not support TLS. Use only on trusted local networks, never expose SSH or FTP ports to the internet, and review the release notes for known limitations.
